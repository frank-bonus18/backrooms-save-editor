gen 不是你能猜出来的值：游戏用服务器 epoch 给每个地标打世代号，同 key + 同 gen 才算同一条。填 0 存档依然有效、图鉴照样列出来，只是世界里不会插那个「已发现」的标记。想让它带标记，就在游戏里真找到一次，游戏会自己写对数字。

上面已经填好默认值，直接点「添加到列表」就行；懒的话点「自动填一条」。key 只是给游戏内部认的英文标识（玩家看不到），nameSeed 只决定地名长啥样。gen 收进「高级」了，不用管。

4 · 直达指定层级

进游戏地址带一个层级参数，载入时就会直接落在那个层级。

只要层级：不用填坐标。游戏里按数字键 1~0 也能跳前十个层级。

注意：作者 11-21 更新后加了布局缓存（houshi.layouts.v1），层级地形会被重建，坐标只保证位置数值，地面长什么样会变。

这两个键是作者 11-21 新增的本地缓存，存档串带不进去，只能靠注入脚本处理。注意：删掉布局键只会重建 201 号层，所以这里改成写入过期版本号。

勾上后，第 3 块生成的「注入脚本 / 手机链接」会连带清理对应缓存；复制存档串不受影响。

地标新字段 gen = 服务器的世界纪元号（epoch），不是你填的；留 0 也能存档，只是世界里不显示该标记。

怎么用

1. 打开游戏页面，进「存档 / 导入」入口粘贴生成的整串；
2. 或者把旧存档串换成新的；
3. 只影响本机游戏进度，不进联机房间共享。

校验码用来防手输错字，不是加密；改错一位就会被判为无效。
