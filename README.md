# 后室存档编辑器

单文件 HTML 工具，用于生成 / 编辑《后室：回不去》（https://backrooms.trenquil.com/）的本地存档串。

## 线上地址

https://frank-bonus18.github.io/backrooms-save-editor/

## 功能

- 解析现有 `HS1z.xxx.XXXXXX` 存档串，编辑时保留原内容
- 层级 20 / 成就 48 / 实体 17 / 物品 3 一键解锁
- 昵称（前缀 + 核心 + 编号，存词表下标）
- 地标表单（选层级 + 英文 key + nameSeed）
- 计数器、钱包（水/盐/功）、语言设置
- 生成直达层级链接、控制台注入脚本、手机 `javascript:` 注入链接
- 自带「自检」按钮与页面报错条

## 说明

纯本地运行，无网络请求；校验码只防手输错字，不是加密。
仅影响本机游戏进度，不进联机房间共享。
